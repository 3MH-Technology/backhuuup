توثيق منصة Wolf Host 🐺

دليل شامل لاستخدام المنصة — من إنشاء الحساب إلى نشر بوتك.

🚀 البداية السريعة

منصة عربية مجانية لاستضافة بوتات التيليجرام (بايثون)، سكربتات PHP، والمواقع الثابتة HTML/CSS/JS.

1
أنشئ حساب

سجل بسم مستخدم وكلمة مرور. حساب واحد لكل جهاز.

2
أنشئ بوت

اختر نوع البوت (بايثون، PHP، أو موقع Static). اكتب الكود أو ارفع ملف.

3
شغّل البوت

اضغط "تشغيل" — البوت يشتغل فوراً مع Webhook ورابط عام.

🤖 أنواع البوتات

بايثون بوتات التيليجرام

استخدم أي مكتبة تيليجرام (python-telegram-bot، telebot، aiogram). يتم عزل كل بوت في بيئة افتراضية خاصة مع تثبيت المتطلبات تلقائياً.

الملف الرئيسي: bot.py
المتطلبات: requirements.txt
نظام البدء: python bot.py
PHP سكربتات ويب

شغل أي سكربت PHP. يدعم Webhook مباشر لاستقبال طلبات HTTP. معزول بـ php.ini مخصص مع تعطيل الدوال الخطيرة.

الملف الرئيسي: index.php
نظام البدء: php -S 0.0.0.0:{port} -c .php/php.ini
الذاكرة: 32MB، المدة: 30 ثانية
Static مواقع HTML/CSS/JS

ارفع موقع ويب كامل (HTML, CSS, JS, JSON, XML, MD) كملف ZIP. يتم خدمته مباشرة عبر HTTP مع رابط عام فوري.

الملف الرئيسي: index.html
نظام البدء: python -m http.server {port}
الوصول: رابط عام /p/{slug}/

📦 رفع الملفات

يمكنك إنشاء بوت بطريقتين:

✏️ كتابة كود

اكتب الكود مباشرة في المحرر. مناسب للتعديل السريع والتجربة.

📁 رفع ملف

ارفع ملف مضغوط ZIP أو ملف فردي. يستخرج ZIP تلقائياً في مجلد البوت.

الامتدادات المسموحة: .py .php .zip .html .css .js .json .xml .md .htaccess .env.example
الحد الأقصى: 5MB لكل ملف، 10MB لكل طلب رفع.

🔗 Webhook

الـ Webhook يسمح لموقعك أو تطبيقك بإرسال طلبات HTTP إلى البوت مباشرة.

الرابط: https://wolf-host.pages.dev/api/webhook/{token}
الطريقة: GET, POST, PUT, PATCH, DELETE
التحديد: 120 طلب/دقيقة

💡 مثال: لربط بوت تيليجرام، استخدم الرابط كـ Webhook URL في BotFather:

https://wolf-host.pages.dev/api/webhook/29b782eae9272db45941d468091f34e4

🌐 الرابط العام

كل بوت يحصل على رابط عام بدون توكن — مناسب للمواقع الثابتة، APIs، والسكربتات.

https://wolf-host.pages.dev/p/{slug}/

الرابط العام لا يتطلب توكن ويمكن مشاركته مع أي شخص. يدعم المسارات الفرعية (مثال: /p/{slug}/page.html).

🔧 مشاكل وحلول

البوت لا يشتغل

تأكد من عدم وجود أخطاء في الكود. تفقد السجلات في لوحة التحكم. إذا استمر، أعد تشغيل البوت.

البوت يتوقف فجأة

قد يكون استهلك الذاكرة المسموحة (128MB). حلل استهلاك الموارد في لوحة التحكم. قد يحتاج الكود تحسين.

خطأ في رفع ZIP

تأكد أن الملفات داخل ZIP من الامتدادات المسموحة. تأكد من عدم وجود ملفات ضارة أو روابط رمزية.

الموقع Static لا يظهر

تأكد من وجود ملف index.html في جذر الـ ZIP. الرابط العام: /p/{slug}/

البوت منتهي الصلاحية

حل الكابتشا في لوحة التحكم لتجديد البوت 4 أيام إضافية. البوتات تنتهي تلقائياً بعد 4 أيام.

❓ أسئلة شائعة

هل المنصة مجانية؟

نعم، مجانية 100% ولا توجد خطط للدفع حالياً.

كم بوت أستطيع إنشاؤه؟

3 بوتات كحد أقصى لكل مستخدم. يمكنك حذف بوت قديم لإنشاء جديد.

هل يدعم بايثون 3.XX؟

يدعم الإصدار المثبت على الخادم (Python 3.x). يتم تثبيت المتطلبات عبر pip في بيئة افتراضية.

هل يمكن استخدام SQLite؟

نعم، البوتات لها صلاحية كتابة في مجلدها الخاص. يمكن استخدام SQLite أو ملفات JSON للتخزين.
